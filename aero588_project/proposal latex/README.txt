AER 588 project proposal

Upload this folder as an Overleaf project, or upload the ZIP.
Set main.tex as the main document. Use pdfLaTeX (Overleaf default).
The proposal uses graphics/option_b_compact.png in the bottom-right corner.
Keep the graphics folder alongside main.tex. No absolute file paths are used.

Included graphics:
- Compact Option B: selected stacked shape-optimization schematic (PNG and SVG).
- Original Option B: horizontal schematic (PNG and SVG).
- Option A: compact plot of the actual CFD overset grid (PNG and SVG).
- Original CFD mesh, total pressure, surface Cp, and field Cp plots (PNG and SVG).

The proposal is set to 11-point font and checks that it stays on one page.
The moving no-slip ground is planned; the saved CFD plots use the preliminary slip-ground solution.
